# Русский на Xiaomi Mi Smart Speaker L09G (Google Assistant) — получилось, без MITM и прошивки

Всем привет! Много лет тема русификации Google-колонок жила на MITM-подмене трафика (mitmproxy + подмена `en-US`→`ru-RU`), эмуляторах со старыми APK и прочей магии, которая в 2026-м уже толком не воспроизводится. Мы зашли с другой стороны и добились стабильного русского на **Xiaomi Mi Smart Speaker L09G** — без MITM, без эмулятора, без кастомной прошивки и без патча приложения. Делимся.

## Главное открытие

**Прошивка L09G сама умеет русский.** Мы просто спросили саму колонку по её локальному API:

```
GET https://<ip-колонки>:8443/setup/supported_locales
```

и получили 59 языков, среди которых `{"locale":"ru","display_string":"Russian - русский"}`. То есть устройство никогда не было проблемой — русский резал только клиент (приложение Google Home не даёт выбрать `ru`). Значит, надо просто протолкнуть `ru` мимо этого ограничения.

## Что понадобилось (пререквизиты)

- Колонка L09G, привязанная к Google-аккаунту, в домашней Wi-Fi.
- Телефон с Google Home. Для «жёсткого» способа — рутованный Android с adb + ПК с Python (`glocaltokens`, `gpsoauth`).
- Никакого рута/UART на самой колонке не нужно.

## Два рабочих способа

**Способ 1 (простой). Язык ассистента = русский на уровне аккаунта.**
Выставляете русский как язык Google-ассистента для аккаунта (в приложении Google → Ассистент → Языки, либо прямо в мастере привязки всплывает экран «язык голосового помощника» с русской галочкой). После этого **новые колонки этого аккаунта поднимаются на русском автоматически** при привязке. У нас так завелась вторая колонка — вообще без танцев, сразу русский.

**Способ 2 (жёсткий, для застрявшей на английском колонки). Пишем локаль прямо в устройство.**
Локальный API колонки на запись требует device-токен (`cast-local-authorization-token`), иначе `401`. Токен достаётся из аккаунта (master-token через браузерный `oauth_token` на `accounts.google.com/EmbeddedSetup` → `gpsoauth.exchange_token` → из homegraph берётся `local_auth_token` устройства). Затем:

```
POST https://<ip-колонки>:8443/setup/set_eureka_info
Header: cast-local-authorization-token: <LAT>
Body:   {"settings":{"locale":"ru"}}
```

**Тонкость, на которой все споткнутся:** локаль должна быть **вложена в `settings`**. Плоский `{"locale":"ru"}` возвращает `200`, но молча игнорируется. С правильным телом и токеном — локаль меняется на `ru`, колонка заговорила по-русски.

## Результат

Русифицировали свои L09G обоими способами: первую — «жёстким» (прямая запись в устройство), последующие — автоматически через язык ассистента аккаунта. **Русский переживает перезагрузку колонки** (проверили ребутом) — то есть это не старый глюк «ответила по-русски один раз и снова английский», а стабильное состояние. Factory reset, само собой, всё стирает — после сброса повторяем.

## Осторожно

Master-token из «жёсткого» способа — это **полный доступ к вашему Google-аккаунту**. Храните аккуратно, не заливайте никуда, при сомнениях — разлогиньте сессии в настройках безопасности аккаунта (это его инвалидирует). App-password для этого флоу, кстати, **не работает** (Google отдаёт `BadAuthentication`) — только браузерный `oauth_token`.

Если надо — распишем пошагово со скриптами. Удачи, наконец-то наши колонки говорят по-русски. 🎉
