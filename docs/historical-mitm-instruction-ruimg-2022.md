# Историческая инструкция русификации (MITM через ru.img-скрипт, датировано 2022)

> Записано со слов пользователя (сессия 2026-07-24). Заявлена для колонок **Nest / Nest Mini**. Пользователь: «Не факт, что рабочая, просто чтобы у тебя она была». То есть — **непроверенный кандидат**, более поздний и хирургический, чем метод 2019 (`historical-mitm-instruction-memu-2019.md`). Анализ и что из него берём — в `attack-vectors-plan-2026-07-24.md` §9.

## Чем отличается от версии 2019 (это и есть ценность)

1. **Не `--replace` по всему трафику, а точечный mitmproxy-аддон `ru.img`** (502 байта — крошечный Python-скрипт, `.img` — просто имя). Мы файл НЕ имеем (в переписке только упомянут как вложение). **Достать ru.img = получить точную рабочую логику: какой хост/поле правится.** Высокий приоритет на добычу.
2. **Явный `--ignore-hosts`-список — эмпирическое знание «что трогать НЕЛЬЗЯ»:**
   - `play.googleapis.com`, `android.googleapis.com` — Play/attestation/загрузка. Не ломать логин/аттестацию.
   - `homecloudcastsdk-pa.googleapis.com` — Cast SDK облако.
   - **`googlehomefoyer-pa.googleapis.com` — Foyer gRPC ИГНОРИРУЕТСЯ.** ← прямо противоречит нашей возне прошлой сессии (мы этот канал мучительно анпиннили) и уточняет вывод §8: закрепляющая правка локали в 2022-методе идёт **НЕ через Foyer**.
   - **IP самой колонки — ИГНОРИРУЕТСЯ.** ← совпадает с нашей находкой (session-report §2, барьер 2): MITM локального канала 8443 вешал «Подключение к устройству». Автор 2022 это знал и просто исключил колонку.
3. **`--ssl-insecure`** — тот же фикс upstream-проверки, что мы вывели сами (session-report §2, барьер 2).
4. **Шаг 12 — ключевой:** когда появится «язык не поддерживается», выбрать **«Английский (США)»** и завершить. Скрипт `ru.img` подменяет нужное поле прозрачно. **«Всё должно получиться с первого раза».**
5. **НЕ упоминает** ни предварительную установку языков Assistant русским-первым (в отличие от 2019 шаг 1), ни Voice Match. Чисто перехват setup-линковки.

## Что из этого следует про цель MITM

Раз игнорируются Foyer (gRPC), локальный API колонки и Play — то `ru.img` правит трафик на **оставшихся** хостах setup-линковки. Наиболее вероятные кандидаты (по onboarding-report §1.D/1.C): `clients3.google.com` (`/cast/orchestration/deviceuserlinksbatch`), `accountlinking-pa`, `oauthaccountmanager`, канал Assistant-settings. Точный ответ — внутри ru.img.

## Шаги (для колонки Nest Mini, версии из инструкции)

1. Настроить колонку как обычно (если уже — к шагу 2).
2. Удалить колонку из дома (останется локально, полный сброс не нужен).
3. MEmu 9.2.0, создать в нём **Android 5.1**.
4. MEmu → настройки → сетевой режим **«Мост»** (выбрать свою сетевую карту).
5. Запустить Android 5.1, войти в аккаунт через Google Play. Установить:
   - **Google Home 2.25.1.5**
   - **Google 10.33.5(.21)** (`googlequicksearchbox_10.33.5.21.apk`)
   - После установки **выключить автообновление** в Play, и **отключить интернет на основном смартфоне/планшете**, если тот же Google-аккаунт живёт на современном Android/iOS с актуальными версиями приложений (иначе аккаунт «подтянет» новые версии).
   - Зайти в Google Home, залогиниться.
6. VirtualBox 7.1.4, установить в нём **Ubuntu 24.04.1**, сетевой режим VBox — тоже **мост**.
7. В Ubuntu: `sudo apt update && sudo apt install mitmproxy`, запустить `mitmproxy` один раз.
8. В Memu (Android 5.1): Настройки → WiFi → долго жать сеть → Изменить → Прокси вручную. Хост = IP ПК с Ubuntu (`ifconfig`), порт **8080**.
9. В браузере Android (Memu) зайти на **`mitm.it`**, скачать и установить CA для Android (дважды кликнуть, задать имя — тогда установится).
10. Выключить mitmproxy.
11. Скачать `ru.img` (вложение). Запустить mitmproxy с точечным скриптом и ignore-списком (**регистр строго соблюдать**):
    ```
    mitmproxy --ssl-insecure \
      --ignore-hosts "play.googleapis.com" \
      --ignore-hosts "android.googleapis.com" \
      --ignore-hosts "homecloudcastsdk-pa.googleapis.com" \
      --ignore-hosts "googlehomefoyer-pa.googleapis.com" \
      --ignore-hosts "<IP адрес колонки>" \
      -s "<путь>/ru.img"
    ```
    Пример IP колонки: `192.168.21.114`.
12. В Memu → Google Home → добавить колонку в дом. Когда появится «язык не поддерживается» — выбрать **«Английский (США)»** и завершить. Должно сработать с первого раза.

## Вложения (упомянуты, у нас их НЕТ)

- `googlequicksearchbox_10.33.5.21.apk` (81.03 МБ) — приложение Google.
- `GoogleHome_2.25.1.5.apk` (67.05 МБ) — Google Home.
- **`ru.img` (502 байта) — сам mitmproxy-аддон. Самый ценный артефакт; достать в первую очередь.**
