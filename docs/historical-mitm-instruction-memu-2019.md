# Историческая инструкция русификации L09G (MITM через Memu-эмулятор, ~2019)

> Записано со слов пользователя (сессия 2026-07-24). Это **реальный метод, которым пользователь пользовался >6 лет назад**, переписанный им подробно с нюансами. **Результат метода:** колонка отвечала на русском **самый первый раз**, затем снова переходила на английский. Это максимум, которого метод давал. Анализ этого результата — в `attack-vectors-plan-2026-07-24.md` §8.

## Чем этот метод принципиально отличается от того, что мы делали в 2026

- **Эмулятор Memu 7.1.1 = Android 5.1.1**, а не рутованный физический телефон на Android 10. На Android 5.1.1 приложения **доверяют user-store CA** — весь наш ад с Magisk / system-store CA / SELinux `chcon` / `ERR_CERT_VALIDITY_TOO_LONG` из подхода №1 прошлой сессии на 5.1.1 **не возникает вообще**. Сертификат ставится штатно через `mitm.it`.
- **Старые версии всего**: Google app `10.33.5.21`, Google Home `2.13.1.10`, mitmproxy `2.0.2`, grpc-tools `0.2.6`, Ubuntu 18.04, `libssl1.0`. Обфускация и allowlist в тех билдах — другие (те, под которые метод и писался).
- **grpc-dump (bradleyjkemp/grpc-tools 0.2.6)** — метод переключается с mitmproxy на grpc-dump в момент ошибки (шаг 13). Т.е. установка языка идёт по gRPC, и старый mitmproxy 2.0.2 его ломает/не тянет — grpc-dump пропускает gRPC чисто, уже после того как байтовая замена en-US→ru-RU отработала на HTTP-фазе.
- **Assistant-языки на аккаунте выставляются ЗАРАНЕЕ (шаг 1): Русский (Россия) ПЕРВЫМ, English (US) ВТОРЫМ.** Это account-layer, не клиентский allowlist.

## Нюансы (со слов пользователя)

- **a.** Во время всех манипуляций на основном телефоне/телефонах желательно не пользоваться приложениями Google, не проверять список языков и т.п.
- **b.** Всё делалось при русском интерфейсе эмулятора, но у некоторых метод работает только при английском (Настройки → Язык и ввод → Язык).
- **c.** Можно играться с языками в приложении Google: Ещё → Настройки → Голосовой ввод → Языки (More > Settings > Voice > Languages). Оставить галочку только на одном (Русский ИЛИ English), либо два языка — первый выбранный ПЕРВИЧНЫЙ. Итого 4 варианта комбинаций, пробовать разные.
- **d.** Вместо Google Play приложение Google можно ставить из APK (упоминалась версия 10.33.5.21).
- **e.** Для SSH сразу под root: в `/etc/ssh/sshd_config` раскомментировать/выставить `PermitRootLogin yes`, затем `service ssh restart`.

## Шаги

1. Отвязать колонку от дома (полный сброс не нужен, достаточно удалить из дома). Выставить языки ассистента: **1-й Русский (Россия), 2-й English (US)**.
2. Установить эмулятор **Memu 7.1.1 (Android 5.1.1)**.
3. В Memu: Настройки → Сеть → Сетевой режим → **Bridge** (поставить драйвер, выбрать свою сетевую карту).
4. Поднять Linux-ВМ (VirtualBox/VMware/отдельный ПК), **Ubuntu 18.04**, сетевая карта тоже **Bridge**.
5. Настройка Linux:
   - `sudo su`
   - `apt update`
   - `apt -y install openssh-server` (дальше работать по SSH — доступен буфер обмена)
   - `cd /root`
   - `apt -y install python3-pip libssl1.0 unzip`
   - `pip3 install mitmproxy==2.0.2`
   - grpc-tools:
     ```
     wget https://github.com/bradleyjkemp/grpc-tools/releases/download/v0.2.6/grpc-tools_0.2.6_Linux_amd64.zip
     unzip grpc-tools_0.2.6_Linux_amd64.zip && rm grpc-tools_0.2.6_Linux_amd64.zip
     chmod 755 grpc-dump grpc-fixture grpc-replay
     ```
   - Запустить `mitmproxy` один раз (q, y — выход) для генерации CA.
   - Извлечь ключ/сертификат для grpc-tools:
     ```
     openssl pkcs12 -in /root/.mitmproxy/mitmproxy-ca-cert.p12 -nocerts -out /root/.mitmproxy/mitmproxy.key
     openssl pkcs12 -in /root/.mitmproxy/mitmproxy-ca-cert.p12 -clcerts -nokeys -out /root/.mitmproxy/mitmproxy.crt
     openssl rsa -in /root/.mitmproxy/mitmproxy.key -out /root/.mitmproxy/mitmproxy-un.key -passin pass:ПАРОЛЬ
     ```
   - IP сервера: `ip -br a`.
6. Установить CA `mitmproxy-ca-cert.p12` в Memu: либо через браузер `mitm.it` при запущенном mitmproxy, либо перетащить .p12 из `/root/.mitmproxy/` (через WinSCP) в окно Memu и установить «для VPN и приложений» (пароль сертификата — пустой/OK; потребуется PIN на эмулятор).
7. В Google Play установить приложение **Google (НЕ запускать)**.
8. Перетащить в Memu **Google Home 2.13.1.10**, **один раз запустить, пройти первичную настройку, НЕ закрывать**.
9. В Android эмулятора: Настройки → Wi-Fi → удержать сеть → Изменить → Прокси → Вручную. Хост = IP сервера, порт = **8080**.
10. В Linux запустить mitmproxy с заменами:
    ```
    mitmproxy --replace /~s/en-US/ru-RU --replace /~s/en_US/ru_RU \
              --replace /~q/en-US/ru-RU --replace /~q/en_US/ru_RU \
              --replace /~s/en_us/ru_ru --http2-priority -k
    ```
11. В эмуляторе открыть приложение Google (может называться «Ассистент»), при запросе выбрать помощника Google. Компас → аватар → Настройки → Ассистент → Языки → убедиться, что стоит **только Русский (Россия)**.
12. В Google Home начать привязку колонки. При выборе комнаты — «Добавить комнату…» и ввести название **на русском** (напр. «Моя»).
13. Как появится ошибка — остановить mitmproxy (q, y) и запустить grpc-dump:
    ```
    /root/grpc-dump --interface 0.0.0.0 --port=8080 \
      --key=/root/.mitmproxy/mitmproxy-un.key --cert=/root/.mitmproxy/mitmproxy.crt
    ```
14. Продолжить настройку. Если появится окно выбора языков — найти Русский (Россия) или English (US). Если окна нет, а ошибка подключения (иная, чем в шаге 13) — остановить grpc-dump (Ctrl+C), снова запустить mitmproxy (шаг 10), закрыть ошибку, продолжить.
15. Проверить: спросить колонку что-нибудь на русском.
16. Если получилось: в настройках колонки отключить «Отправлять в Google данные об использовании и отчёты о сбоях».
